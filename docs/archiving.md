# Citation and archival release

Use [CITATION.bib](../CITATION.bib) for *Z is Diophantine in Q*, Version 14, dated November 9, 2026, and for the historical manuscripts and research handoffs. The current manuscript is [manuscripts/quartic_v14.pdf](../manuscripts/quartic_v14.pdf), with [TeX source](../manuscripts/quartic_v14.tex). Cite the version and commit or file hash when discussing an exact artifact.

The manuscript author field is blank, and the BibTeX entries intentionally omit author fields. Collaboration credit appears in the [README](../README.md). There is no `CITATION.cff`: the CFF 1.2 schema requires an author record, and the repository does not invent a person or organization to fill it.

The [523/540-variable package](../quartics/quartic-523-540/) and its [guide](quartic-523-540/README.md) remain historical proof baselines.

## DOI status

No DOI is recorded in the repository's citation metadata. A GitHub release and a DOI deposit are separate records. Any later deposit should identify the exact manuscript, polynomial, evidence files and hashes it preserves, and should respect the blank-author convention. Add a DOI to the citation metadata only after the deposit exists and its contents have been checked.
