# Conditional local connection appendices, version 1

These appendices contain the full unchanged project arguments, not a substitute consisting of review verdicts. [Appendix O2](o2/PROOF.md) supplies the auxiliary classical-point, type, Tate-twist, same-fiber and unitary-transfer arguments. [Appendix O3](o3/PROOF.md) supplies the nonordinary RED and RED-to-first-order arguments. Their hypotheses and retained inputs are part of their statements.

The [O2 independent review](reviews/o2/REVIEW.md) and [O3 independent review](reviews/o3/REVIEW.md) accept only the bounded connections. Original author prose saying review was pending is preserved as history. The [O2 metadata clarification](reviews/o2-clarification/CLARIFICATION.json) explicitly retains its final-edition qualification.

O2 uses the [original auxiliary construction](../../../../research/version14/evidence/ceggps-local-reviews/dependencies/ceggps-route-001/PROPOSAL.md) and the [original consolidated local proof](dependencies/consolidated003/PROOF.md). The currently incorporated versions are the [restricted local proof](../restricted-ceggps/proof-v1.md) and [auxiliary route](../restricted-ceggps/auxiliary-route-v1.md). They have their own transport and review records; they are not presented as byte-identical replacements for the original pins. The original [normalization and consumer discussion](dependencies/ht002/REVIEW.md) and [RED bridge](dependencies/ht002/RED-BRIDGE.md) are retained.

The [O3 retained inputs](o3/RETAINED-INPUTS.json) include type multiplicity, ordinary and nonsupercuspidal alternatives, exceptional points, the actual first-order module construction, general-type criteria and cycle statements. O2 type detection alone does not supply multiplicity one. CEGGPS, BM and Dospinescu version qualifications remain explicit. O4 global modularity and O5 residual branches are not closed by these appendices.

Original source hashes and locators remain in each appendix's SOURCE-PINS.json. Full third-party papers and extracted pages are excluded. TRANSPORT.json identifies exact copies and the proposed manuscript binding. This version is an incorporation proposal; no installation or final release approval is claimed.
