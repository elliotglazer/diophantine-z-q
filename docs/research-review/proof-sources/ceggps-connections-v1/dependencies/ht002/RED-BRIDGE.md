# Exact locally algebraic extensions imply the density required by Dospinescu

Author: `/root/astra_v14_baseline_compiler`. Proposed explanatory connection only; no independent approval.

Let Pi be an absolutely topologically irreducible admissible unitary E-Banach representation with nonzero locally algebraic vectors. Let

    0 -> Pi -> X -> Pi -> 0

be an exact sequence in the Banach category for which the corresponding sequence of locally algebraic vectors is exact. Let C be the closure of X^lalg in X. Since Pi^lalg is nonzero, its closure in Pi is a nonzero closed invariant subspace, hence all of Pi. Thus Pi is contained in C. The subspace C/Pi is closed in X/Pi, since C is closed and contains Pi. Exactness on locally algebraic vectors says that its image contains Pi^lalg. That subspace is dense in the quotient Pi, so C/Pi equals X/Pi. Together with Pi contained in C, this proves C=X.

Therefore every extension counted by BM Definition 4.17 belongs to the subspace spanned by extensions with dense locally algebraic vectors. Apply the selected Dospinescu theorem identifying the latter subspace with fixed-determinant de Rham extensions. At a supercuspidal Weil parameter its dimension is one, because the theorem's special exception has reducible Weil parameter. The BM subspace has dimension at most one, which is (RED).

All representations and extensions have the same fixed central character. On the Galois side the selected comparison uses determinant epsilon times that character. There is no change to an unrestricted-determinant Ext group. The implication proved here is exactness implies density; no converse is asserted or used. This avoids the thesis converse criticized in the inspected author's Remark 1.6. The final-edition comparison of the selected Dospinescu theorem remains an external qualification.
