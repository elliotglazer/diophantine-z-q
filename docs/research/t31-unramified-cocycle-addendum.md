## Construction and exact connecting argument

Put `d = Module.finrank ℚ L`, which is positive for every original field `L`.

### 1. Actual finite local Frobenius quotients

For every `p : Nat.Primes` and every positive `n`, define

```text
N_n = p^n - 1,
K_n = ℚ_p(μ_(N_n)) inside the actual AlgebraicClosure ℚ_p.
```

`Fields.muField` and its positive-level instances provide the genuine finite Galois field `K_n`. The source proof `range_autToPow_eq_zpowers'` identifies the **image of the actual action on roots** with the subgroup generated by `p` in `(ZMod N_n)ˣ`. The source arithmetic proof establishes `orderOf(p mod N_n) = n`, including `p=2,n=1`.

`frobeniusPowerEquiv p n` is the explicit-generator isomorphism from `C_n = Multiplicative (ZMod n)` to that subgroup: the residue class of `1` maps to `p`. It is not an arbitrary isomorphism chosen from `IsCyclic`.

`localFrobeniusQuotient p n : GQp p →* C_n` is obtained from the actual normal restriction to `K_n`, the actual root action, and that explicit coordinate. Its continuity, local constancy, and surjectivity are proved. Its value satisfies

```text
↑(frobeniusPowerEquiv p n (q_n g)) = cyc N_n (resp p g).
```

The right-hand side uses the original `resp`, not a substituted local embedding. The equality is supplied by the unchanged `finiteCyc_restrict_eq_cyc` proof, which uses the exact `IsAlgClosed.lift` selected inside `Field.absoluteGaloisGroup.map`.

The reduction `C_(2n) → C_n` is the old actual `ZMod.castHom` reduction. The new proof checks cyclotomic-character reduction on a primitive smaller root and checks that the explicit generator `p` maps to the explicit generator `p`. Consequently,

```lean

  localFrobeniusQuotient p n
```

is proved for every positive `n` and every finite prime. The doubled map and its continuity are constructed, not assumed. No separate identification of a maximal unramified absolute Galois quotient with `ℤ̂` is used or claimed.

### 3. Actual integer map and contracted prime

For this container `M`, let

```text

```

Integrality of an original `𝓞 L` element is transported by the actual ring map from `ℤ` to `ℤ_p`. This constructs

```text

```

For `g : GQp p`, put `σ = localRestriction L p g` and let `τ` be its actual normal restriction to `M`. The proof verifies on **all integer elements**:

```text
τ • integerEmbedding(x) = integerEmbedding(σ • x).
```

Both actions are Mathlib's canonical integral-closure actions. Neither a surrogate Galois action nor a separately selected field equivalence is used.

Choose a maximal `Q : Ideal S` above the maximal ideal of `ℤ_p`. The source spectral-norm proof shows that `S` is local; therefore this same `Q` is stabilized by every actual local automorphism. Define


### 5. Kernel inclusion through the exact global inertia

Assume `q_n g = 1`, with `[L:ℚ] ∣ n`. The character identity from step 1 implies that the original global action fixes a primitive `N_n`-th root. The exact embedding and normal-restriction equations imply that `τ` fixes its image in `M`.

The root equation from the **same r** in step 4 therefore gives `p^r = 1 mod N_n`. Since the genuine Frobenius generator has order `n`, `n ∣ r`.

The original global Galois fundamental identity for **P above (p)** is retained in its full form:

```text

```

With `e=1`, this proves `f(P/ℤ) ∣ [L:ℚ]`. The exact residue-field cardinality is also proved:

```text

```

Hence `f(P/ℤ) ∣ [L:ℚ] ∣ n ∣ r`, so the Frobenius exponent `p^r` is the identity on every element of this same finite global residue field. The canonical map


is used, not an assumed residue-field identification. Combining its finite-field power identity with the all-element embedding equivariance gives

```text

```

Thus `σ • x - x ∈ P` for every original integer element: `σ` is in the **actual** `P.inertia Gal(L/ℚ)`. This also proves prime preservation; inertia is the canonical subgroup, not an unrelated root-action group. The pinned global inertia-cardinality theorem gives `|inertia(P)|=e(P)=1`, so `σ=1`.

This proves the needed actual kernel inclusion. It never identifies the whole Galois group of the larger container with its cyclic root-action image.
