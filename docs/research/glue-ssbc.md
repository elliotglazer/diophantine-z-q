## Proof (trace-form criterion; characteristic 0)

Let `A ⊆ End_k V` be the `k`-span of `ρ(G)` (the range of `Representation.asAlgebraHom`) and
`A_E ⊆ End_E(E ⊗ V)` the `E`-span of `ρ_E(G)`. Say that the trace form of a subalgebra `B ⊆ End W` is
nondegenerate (`TraceNondeg B`) when `x ∈ B` and `tr_W(xy) = 0` for all `y ∈ B` imply `x = 0`.

1. `isSemisimpleRepresentation_iff_range`: `ρ` is semisimple iff `V` is a semisimple `A`-module.
   (Mathlib's `asModule` criterion, transported along the surjection `k[G] → A` with
   `LinearMap.isSemisimpleModule_iff_of_bijective`.)
2. `isSemisimpleRing_of_isSemisimpleModule`: `A` embeds `A`-linearly into `V^n` (`a ↦ (a b_i)_i` for a
   basis `b`), so `A` is a semisimple ring.
3. `traceNondeg_of_isSemisimpleModule` (needs char 0): the radical `{x | ∀ y, tr(xy) = 0}` is a left
   ideal (since `tr(cxy) = tr(x(yc))`). In a semisimple ring it is generated by an idempotent `e`
   (`IsSemisimpleRing.ideal_eq_span_idempotent`). Then `tr e = tr(e·e) = 0`, and in characteristic 0 an
   idempotent endomorphism of trace 0 is 0 (`LinearMap.IsIdempotentElem.trace_eq_zero_iff`, since
   `tr e = rank e`). So the radical is 0.
4. `traceNondeg_baseChange` (any `E/k`): let `x = Σ_g c_g ρ_E(g) ∈ A_E` be orthogonal to `A_E`. For each
   `k`-linear functional `f : E → k`, `X_f = Σ_g f(c_g) ρ(g) ∈ A` is orthogonal to `A`, because
   `tr_k(X_f y) = f(tr_E(x · y_E))` (`LinearMap.trace_baseChange`) and `y_E ∈ A_E`. So `X_f = 0` by step 3.
   Taking coordinates in the basis `1 ⊗ b_i` of `E ⊗ V` (`Algebra.TensorProduct.basis`), every
   coordinate of `x(1 ⊗ v)` is killed by every `f`, hence is 0 (`Module.forall_dual_apply_eq_zero_iff`),
   so `x = 0`.
5. `isSemisimpleRing_of_traceNondeg`: `A_E` is finite-dimensional, so artinian, and its Jacobson radical
   is nilpotent (`IsArtinianRing.isNilpotent_jacobson_bot`). For `x` in the radical and any `y`, `xy`
   is in the radical (a two-sided ideal), so it is nilpotent and has trace 0. So `x = 0`, the radical is
   `⊥`, and `A_E` is a semisimple ring (`IsArtinianRing.isSemisimpleRing_iff_jacobson`).
6. Then `E ⊗ V` is a semisimple `A_E`-module, so `ρ_E` is semisimple (step 1 over `E`).

This is the standard argument in characteristic 0. In characteristic 0, a subalgebra of `End V`
is semisimple iff its trace form is nondegenerate. References (STANDARD; locators UNVERIFIED, no
network): Curtis–Reiner, *Representation Theory of Finite Groups and Associative Algebras*, §§25 and 69;
Bourbaki, *Algèbre* VIII §12 for the general separable case.
