## 1. The statement

```lean
def RingClassLattice : Prop :=
  ∀ (m f : ℕ) [NeZero m] [NeZero f], Squarefree m →
  ∀ (J : integralIdealsPrimeTo (conductorOrder (QNeg m) f).conductorModulus)
    (s : IdeleGroup (𝓞 (QNeg m)) (QNeg m)),
    ringClassIdeleQuotient (conductorOrder (QNeg m) f) (icl s) =
      (conductorOrder (QNeg m) f).picClass J →
    ∃ k : QNeg m, k ≠ 0 ∧ idealOf m f s = (fun x => k * x) '' idealMeetOrder m f J
```

`K = ℚ(√−m)`, `O = ℤ + f𝓞_K`, `𝔣` its conductor (Tau Ceti's `conductorModulus`, finite part `O.conductor`),
`idealOf m f s = {j ∈ K : s_f⁻¹ j ∈ Ô_O}` with `Ô_O` the closure of `O` in Mathlib's finite adeles,
`idealMeetOrder m f J = J ∩ O`. The hypothesis `Squarefree m` is not used by the proof.

## 2. The proof (all VERIFIED, compiled)

Write `𝒪̂` for Mathlib's `integralAdeles`, `e_v` for the exponent of `v` in `𝔣` (`Modulus.exponent`), and
`𝔣̂ = {z ∈ 𝔸_{K,f} : |z_v|_v ≤ exp(−e_v) for all v}` (`fHat`; `e_v = 0` off `𝔣`, so `𝔣̂ ⊆ 𝒪̂`).

**(a) `Ô_O = ℤ + 𝔣̂`** (`mem_latHat_O_iff`). `ℤ + 𝔣̂` (`oHat`) is an additive subgroup containing `𝔣̂`, which contains
the open set `f𝒪̂` (`f ∈ 𝔣`), so it is open, hence closed; it contains `O = ℤ + f𝓞_K`, hence `Ô_O`. Conversely,
for `w ∈ 𝔣̂` density of `K` (Mathlib's `denseRange_algebraMap`) gives `x ∈ K` with `w − x ∈ f𝒪̂ ⊆ Ô_O` (t5-glue's
`fIntAd_sub_latHatO`); then `x ∈ K ∩ 𝔣̂ = 𝔣 ⊆ O` (`mem_integers_of_valuation_le_one`, Tau Ceti's
`mem_finitePart_of_forall_mem_pow_exponent`, Mathlib's `intValuation_le_pow_iff_mem`).

**(b) The local computation** (`setOf_mul_mem_latHat_eq`). Let `y ∈ 𝔸_{K,f}`, `J` an ideal of `𝓞_K`, `a, a' ∈ ℤ` with
(D1) `y j ∈ 𝒪̂ ⇔ j ∈ J` for `j ∈ K`; (D2) `|y_v − a|_v ≤ exp(−e_v)` for `v ∣ 𝔣`; (D3) `a a' − 1 ∈ 𝔣`. Then
`{j ∈ K : y j ∈ Ô_O} = J ∩ O`. ⊇: for `j = b + f y₀ ∈ J ∩ O`, `y j − ab = (y − a) j + a f y₀` is in `𝔣̂` at
`v ∣ 𝔣` and integral elsewhere (D1); apply (a). ⊆: (a) gives `b` with `y j − b ∈ 𝔣̂`, so `y j ∈ 𝒪̂`, so `j ∈ J` (D1);
`j − a'b = −(aa' − 1) j − a'(y − a) j + a'(y j − b) ∈ 𝔣̂` at `v ∣ 𝔣` and integral elsewhere, so `j − a'b ∈ 𝔣` and
`j ∈ ℤ + 𝔣 ⊆ O`.

**(c) Ray classes** (`ringClassLattice`).
1. Tau Ceti's `exists_unitEmbedding_mul_mem_ideleCongrOneSubgroup`: `t = α s` (`α ∈ Kˣ`) is congruent to one modulo
   `𝔣`; `icl t = icl s`.
2. `rayClassQuotient_mk_of_mem`: the ray class of `[t]` is `rayClassMk` of the fractional ideal `I_t` of `t_f`.
3. The hypothesis says `rayClassToPic(rayClassMk I_t) = picClass J = rayClassToPic(idealClass J)`, so
   `rayClassMk I_t · [J]⁻¹` lies in the kernel; `mem_ker_rayClassToPic` gives `J' = (β)` prime to `𝔣` with `β ∈ O`
   and `idealClass J' = rayClassMk I_t · [J]⁻¹`; `mem_ray_iff` gives `γ ∈ Kˣ`, `IsCongrOne 𝔣 γ`, with
   `I_t = (γ)(β)J` in the group of invertible fractional ideals.
4. `k = α⁻¹γβ` and the finite idele `y = s_f⁻¹ k`, whose fractional ideal is `J⁻¹`. (D1): for `j ≠ 0`, `y j` is a
   finite idele with ideal `J⁻¹(j)`; Tau Ceti's `toFractionalIdeal_le_one_iff` turns `y j ∈ 𝒪̂` into
   `J⁻¹(j) ≤ 1`, i.e. `(j) ≤ J` (`inv_mul_le_one_iff`, `mul_mem_intAdeles_iff`).
   (D2): `y = t_f⁻¹ γ β` and `β = a + f y₁`: `y − a = (t_f⁻¹ − 1)γβ + (γ − 1)β + f y₁`, each term bounded by
   `exp(−e_v)` at `v ∣ 𝔣` (the congruence of `t⁻¹`, `IsCongrOne.valuation_sub_one_le`, `valuation_eq_one`).
   (D3): `(β) + 𝔣 = 1` gives `a u ≡ 1 (mod 𝔣)`; `𝓞_K/𝔣` is finite, so `a' = a^{ord(a)−1}`
   (`exists_int_inv_mod_conductor`).
5. (b) gives `{j : y j ∈ Ô_O} = J ∩ O`, i.e. `idealOf s = k·(J ∩ O)`.
