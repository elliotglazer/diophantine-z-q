# DPRM Basic Theorem: published source statement

For each enumerable predicate on finite tuples of positive integers, there is an integer-coefficient polynomial whose vanishing, with finitely many existential positive-integer witnesses, represents exactly that predicate. The polynomial is fixed for that predicate.

Matiyasevich, Diophantine representation of enumerable predicates, Mathematics of the USSR-Izvestiya5(1971),1–28, Basic Theorem printed3; definition(2), positive-variable convention and integer-witness conversion printed2.
