# Bertrand interval theorem

Project paraphrase of P. Erdos, Beweis eines Satzes von Tschebyschef, Acta Scientiarum Mathematicarum5 (1932),194–198, Sections4–5 pp.197–198. Original institutional PDF SHA256 e9c7f6658e7ffb67b11d4efb931db4c1433417999e3efe9fb48470d45688a5ba.

**statement**: For every integer m>1 there is a prime p with m<p<2m.

**objects**: Positive integers and rational primes.

**hypotheses**: m is an integer greater than1.

**quantifiers**: Every integer m>1.

**parameter_range**: The full finite range, not only sufficiently large m.

**uniformity**: The factor2 is absolute.

**constants**: Upper endpoint2m.

**normalizations**: Strict lower and upper inequalities. Even if the upper endpoint is written non-strict in an intermediate argument, 2m is composite for m>1.

**exceptional_cases**: m=1 is excluded; no assertion about arithmetic progression primes.

**limit_order**: Fix m, then choose a prime in the interval.
