# GTZ-DEGREE-PULLBACK

Project paraphrase, not a copy of the publication.

Source: Ben Green, Terence Tao and Tamar Ziegler, An inverse theorem for the Gowers U^{s+1}[N]-norm, Annals of Mathematics 176 (2012), 1231–1372. Final publisher PDF SHA256 cd320f5c1217df9bb41395e847ae2a924e70521021ca1b01c7abc20550123be1. Lemma E.8(vi), p.1354, with proof reference p.1356.

**statement**: Precomposition of a degree-at-most d nilcharacter by a fixed integer linear map is again a degree-at-most d nilcharacter. The same precomposition preserves degree-d symbol equivalence.

**objects**: An integer linear map T:Z^k to Z^ell, a degree-filtered nilcharacter on Z^ell and its lower-degree tensor comparison.

**hypotheses**: Ordinary degree filtrations; T is a fixed standard integer linear map; the actual test, polynomial orbit and lower-degree representation satisfy their stated conditions.

**quantifiers**: Every such fixed T and every such represented nilcharacter and equivalence.

**parameter_range**: Fixed finite dimensions and ordinary degree bound d.

**uniformity**: The same target geometry and test are retained; only the polynomial orbit is precomposed.

**constants**: No new test Lipschitz constant or target dimension is required.

**normalizations**: The symbol comparison is the pullback of the original full tensor comparison.

**exceptional_cases**: Zero maps and rank-deficient maps may lower the actual degree. No arbitrary linear map is asserted to preserve a multidegree rectangle.

**limit_order**: Check the source and target degree filtrations, then precompose the orbit and its lower-degree comparison.

Application boundary: The printed E8(vi) contains a domain mismatch for chi-prime, and its B5 citation has a composition codomain typo. The current fixed-integer-map application is checked directly: each iterated difference after precomposition equals the original iterated difference in the image directions. The unchanged global test retains its vertical identity; a lower-degree representation pulls back the same way. No unchecked multidegree or arbitrary limit-coefficient claim is used.
