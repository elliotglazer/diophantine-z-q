# TeX incorporation review for the proposed 214 family

This directory records the new editorial application from the frozen public
214 proof packet to the complete readable TeX manuscript. It preserves the
original fourteen applications and every earlier public review unchanged.
The source-first reconstruction was frozen before consulting their inventory.
`INITIAL_SOURCE_USES.json` records prior exposure, actual reading and limits.

`ADAPTATION.json` is an author contract, not independent mathematical
acceptance. It binds the new TeX, source map, generator and original application
passages. Its nine obligations explain this editorial application; the original
mathematical obligations remain in their exact original contracts. The new
passage connections identify the current TeX receiving each of those arguments.

The immutable initial reconstruction selected the frozen V15 foundation.
Newly discovered upstream corrections require a separate current application:
`FOUNDATION_TRANSITION.md` compares the actual GI lift, fixed-modulus
Tao–Ziegler and CMH changes to their 214 consumers, and
`FOUNDATION_APPLICATION.json` supplies nine obligations and exact bindings.
The complete final amended V16 is the current receiving foundation. The old
V15 source and the fourteen original contracts remain historical evidence;
their approvals do not automatically accept this changed application.

`FINDINGS.json` preserves objections, historical and current dispositions and
remaining work. Preliminary source comparison does not constitute Astra or
controller acceptance. A separately authored decision must identify its actual
review conditions and exact scope. Controller eligibility is not authenticated
by the checker.

Run `python3 -B research/quartic214-manuscript-review/check_records.py --self-test`
for record consistency and negative controls. Add `--release` to require actual
PDF/build bindings and a separately authored current decision. No TeX build,
quartic expansion or arithmetic proof check is performed by this checker.
The PDF/build record is prepared by the serial resource-limited manuscript
builder. A structural PASS establishes only the stated byte bindings,
coverage links and declared decision fields.

Changed TeX, sources, map, generator, original application or PDF invalidates
the affected bindings. Compare the changed application before authoring a new
contract or requesting reviewer acknowledgement. Never edit an earlier approval
or populate a decision on the reviewer's behalf.
