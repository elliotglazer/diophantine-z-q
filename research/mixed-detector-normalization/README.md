# 380 variables with 644-digit coefficients

This conditional research layer above #16 uses the package's two existing
detector normalizations together. Its six high tests reach order 46 without
adding coordinates. That is sufficient for anchor 3^2010 and maximum
coefficient **28902*3^1340: 644 digits, 2139 bits**.

The full polynomial has **380 variables including the input**, 349
quadratic residuals and 26025 quartic monomials. It retains the parent's
default variable count and its optional route's smaller coefficients.

Read [PROOF.md](PROOF.md), [APPLICATION_CONTRACT.json](APPLICATION_CONTRACT.json),
[FINDINGS.json](FINDINGS.json) and [HANDOFF.md](HANDOFF.md).
The new detector inputs differ from the parent's; their soundness and
simultaneous completeness are proved separately within the inherited
conditional assumptions. No order-47 or global-optimality claim is made.

```sh
python3 -B research/mixed-detector-normalization/reproduce.py --output build/mixed380
```

Use a new or empty output directory. Python 3 and Node suffice without
network or third-party packages. Replay checks the three actual changed
weight rows, every outside row and guard, exact weight/local exponents,
all three height margins, five negative controls, compiler identities,
four conic transports and every scaled polynomial coefficient. Source
bindings are checked before and after. These computations do not establish
the uniform arithmetic proof or inherited global theorem.

EXPECTED.json specifies the full deterministic decimal expansion and its
hash. The table is generated by replay and uploaded by CI, not committed
in this new directory. Parent packets and their historical review bindings
remain unchanged. The PR links separately authored review and public
readback at immutable revisions. Current Version 13 is not replaced.
