# Version 17 historical navigation continuation

This author implementation preserves the old integration checker, record, independent review and original authority files byte for byte. It adapts only that checker's calls to `safe(ROOT, README.md)` and `safe(ROOT, .github/workflows/quartic214-manuscript.yml)` to the two exact prepromotion navigation files. Its old current-navigation equality checks, original historical validator, old independent receipt and all original controls still run. The original validator also reads exactly two superseded selector/policy identities, `docs/current-manuscript.json` and `docs/release-policy.md`, from their frozen prepromotion bytes. Every other path remains a current repository read. The real current selector is separately validated with the unchanged complete-pair checker; trusted-base integer enforcement remains mandatory in Research checks.

`FROZEN.json` records the unchanged authority hashes. `CONTINUATION.json` binds those files, this implementation, the prepromotion navigation files, and actual current README/workflow/selector/policy bytes and the version-check implementation, tests and workflow. Active CI requires a separate independently authored `REVIEW.json` bound to that continuation. Author mode does not supply or waive either old acceptance or new CI acceptance.

The new review schema is `v17-navigation-continuation-review/v1`; fields are `authors` equal to [`/root`, `/root/pr30_final_repair_review`], independent `reviewer`, `decision` equal to `accepted-at-stated-scope`, `controller_acceptance` and `mathematical_acceptance_renewed` both false, sorted `historical_substitutions` containing exactly the four navigation/selector/policy paths, nonempty `limitations`, and `record` containing the continuation's repository path, SHA-256 and byte count. The review must assess the actual current navigation changes; hashes alone do not authenticate reviewer identity or establish mathematical acceptance.

The workflow change replaces the prior wrapper command and adds only the Version 17 trigger. No mathematical file is substituted and no old verdict is renewed for changed mathematics. Run with `--self-test --author-check` before independent review and `--self-test --reviewed-artifacts` afterward. The old checker uses Unix resource limits, so this gate runs on Linux as before.
