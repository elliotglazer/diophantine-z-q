# Historical CI entry points after Version 17

These four fixed modes run the unchanged Version16 correction check, original manuscript assembly and formula-correction check, and revision2 receiving gate. Original scripts, mathematical files, manifests, source maps and old independent receipts remain unchanged. Their full validations and rejection controls still run.

Version16 reads its exact original CITATION.bib, manuscripts/README.md and workflow identity. Both original-assembler modes read the archived Version16 current-manuscript selector. Revision2 reads that selector and its original workflow identity. All other paths remain live. The real current manuscript profile and its complete source/PDF/build mapping are validated before any historical reads are installed. The existing Paper build job separately enforces trusted publication order.

BINDINGS.json binds the exact commands, original manifests/source map, actual current navigation files, workflow changes, archives and implementation. It is an author binding record, not an independent acceptance. Protected review must assess this compatibility delta and its current consumers. No approval or mathematical acceptance is generated by this runner. Historical checks still concern their own editions, even when they print historical current/version labels.

Each invocation rejects arbitrary commands, write-mode assembly, undeclared modes, missing substitutions and proof substitution, and checks that proof bytes stay live and current-selector reads are restored. The wrapper never edits the checkout. All existing build commands, resource limits and final git-diff checks remain in their workflows. New archive copies are exact raw Git blobs; no checkout newline conversion is applied.
