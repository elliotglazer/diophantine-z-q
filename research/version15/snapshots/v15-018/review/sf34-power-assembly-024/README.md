# Test powers and factor assembly

This author packet fixes the component conventions used by both detector products. The checker verifies 72 exact rational polynomial row identities and four D-inverse identities. It does not replace the point interpretation of the root charts. The prior accepted 022 identities are inputs, not new review claims.

Run `python check.py` from any directory. The source IR hash is checked before use. No manuscript or historical source is changed.
