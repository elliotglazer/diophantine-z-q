# Explicit 222-variable quartic family

The selected presentation is tables/sparse222-polynomial.json: 2,277 coordinate monomials (2,278 parameter-separated terms), degree four, integer coefficients of content one. Its first coordinate is the fixed input. tables/sparse222-ir.json gives the 196 quadratic residuals and their strictly positive rational square weights. The raw presentation is retained separately; it has 2,961 coordinate monomials.

For A_N = 149^(2N+1), the coefficient height is exactly A_N^2+1 for N >= 53. This explicit coefficient-size threshold is not the defining threshold. The inherited arithmetic theorem requires N >= N0 for an ineffective N0; this package does not compute or certify N0, and does not assert that choosing N=53 defines the integers.

## Reproduce the finite calculation

Python 3 with only its standard library is sufficient. From this directory:

    python -B verify.py
    python -B generate.py --N 53 --output polynomial-N53.json

The generator refuses to overwrite an existing output. It instantiates the selected table and marks the defining-threshold premise uncertified. The verifier independently expands every positive weighted square, compares the complete coefficient table, and checks variables, degree, content, support counts and the uniform coefficient bound for all N >= 53. It does not prove the inherited arithmetic theorem or replace the independent rational-map reviews.

Files under provenance are byte-preserved: their original proposal statuses and historical absolute paths are not rewritten. Acceptance belongs to the separate review files. Historical builders and research checkers may require the original workspace layout; the two root scripts above are the portable finite reproduction interface.

The scalar-contact step preserves the claimed integer projection through its arithmetic argument; it is not advertised as a bijection of every old and new witness. Other stage-specific inverse domains and exceptional cases remain in the respective proofs and maps.

Positive weights preserve simultaneous vanishing over the rationals. The trace change divides only by the proved-nonzero q1-square; zero trace values are allowed. No new mathematical equivalence is asserted by this packaging operation.
