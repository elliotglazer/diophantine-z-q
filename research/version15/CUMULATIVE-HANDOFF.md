# Version 15 cumulative handoff

This handoff selects the 222-variable quartic family alongside the original huge-polynomial construction and the retained 314-variable decimal quartic. Read the [current manuscript](snapshots/v15-222-004/manuscript/quartic_v15.pdf). Start with the [artifact index](ARTIFACT-INDEX.md), [222-variable package](quartics/quartic-222/README.md), and [release notes](RELEASE-NOTES.md).

The selected sparse family has 196 quadratic residuals and 2,277 nonzero coordinate monomials. A_N = 149^(2N+1) is a fixed integer coefficient parameter. Its coefficient height is A_N² + 1 for N >= 53; the defining theorem still requires a separate ineffective threshold N0. A generated table at a chosen N does not certify that N exceeds N0.
