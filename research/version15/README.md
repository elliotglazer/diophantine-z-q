# Version 15 research

Read the [manuscript PDF](snapshots/v15-222-004/manuscript/quartic_v15.pdf) or [TeX source](snapshots/v15-222-004/manuscript/quartic_v15.tex), then use the [artifact index](ARTIFACT-INDEX.md) for the exact polynomial tables and reproduction tools.

The selected family has **222 total variables**, **196 quadratic residuals**, and **2,277 nonzero coordinate monomials** in its sparse quartic. The original huge-polynomial construction and the 314-variable decimal quartic remain available. The prior 233-variable manuscript and artifacts remain unchanged in [snapshot018](snapshots/v15-018/ARTIFACT-INDEX.md).

For A_N = 149^(2N+1), the coefficient height is A_N² + 1 when N >= 53. This numerical estimate is separate from the theorem's ineffective defining threshold N0. Generating a table for a chosen N does not certify the defining premise.
