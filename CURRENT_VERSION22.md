# Version 22

[PDF](manuscripts/quartic_v22.pdf) and [TeX](manuscripts/quartic_v22.tex)
adopt Jose Brox's explicit 175-variable quartic: 3,196 monomials,
coefficients below 2^802 and 73,080 bytes of plain decimal notation.

Version 22 is the published record. It was merged through PR178 and
[released](https://github.com/elliotglazer/diophantine-z-q/releases/tag/quartic-175-version-22) on 28 November 2026; the release page states what each
review covered. Version 21 is preserved as the previous release.
The integer-to-zero direction for the 175 uses Bhargava–Burungale
arXiv:2611.16130v2, Theorem 2.3; soundness does not use that preprint.
See [dependencies](research/version22/DEPENDENCIES.md),
[review repairs](research/version22/FABLE-REPAIR-RECORD.md), and
[release preparation](research/version22/RELEASE-MANIFEST.json).
