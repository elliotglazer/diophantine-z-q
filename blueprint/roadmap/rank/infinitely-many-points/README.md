# The rank hypotheses as infinitely many rational points

The positive-rank hypotheses CR₃^Rk, CR₃^TYZ,Rk, CR₃^TYZ_Cl,Rk and CR₃^DL,Rk conclude that a curve
$C_d:y^2=x^3-d^2x$ has a rational point of infinite order, so their statements involve the group law
on $C_d(\mathbb Q)$. This section restates each of them with the conclusion that the equation
$y^2=x^3-d^2x$ has infinitely many rational solutions, a statement that mentions no group law. For
$d\ne0$ the two conclusions are equivalent: a point of infinite order has infinitely many distinct
multiples, and conversely, by Mordell–Weil, a finitely generated group of points all of finite
order is finite. Hence each new form is equivalent to its positive-rank form, with the same
premises, and the main theorem holds under the minimal height hypothesis and any of them.

Throughout, $C_d$ is the curve $y^2=x^3-d^2x$, as in the rest of the positive-rank chapter.

## Equivalence with the positive-rank forms

Each equivalence holds pointwise, since every curve in these hypotheses has $d\equiv5\pmod8$, so
$d\ne0$. The main theorem in each of the four forms is
[the main theorem from the infinitely-many-points forms](../../main/main-theorem-infinitely-many-points.md).
