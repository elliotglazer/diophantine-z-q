# The inverse abscissa template

The template $\mathtt{raw\_inverse\_x}$ has $7$ parameters and no witnesses: the point
$p=(X_0,\dots,X_4)$ and the pair $v=(X_5,X_6)$. Its formula is $I\!X(p,v)$ and its
polynomial is $[\![\mathtt{raw\_inverse\_x}]\!]=\kappa(I\!X(p,v))^2$. It expresses $v=1/x(p)$,
with value $0$ at the identity.

This is a definition (template index $3$).
