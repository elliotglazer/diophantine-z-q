# From the Rédei matrix to Rédei's bits

For an odd number $d$ and a nonempty set $B$ of its primes, the Rédei matrix of $d_B$ is the
Laplacian $L_B$ of the bits $a_{qp}=[p/q]$ of $d$, bordered by the column $z_B$ exactly when
$y(B)=0$. Its kernel is $\{0,e_{d_B}\}$ exactly when $g_d(B)=1$. The first two articles prove the last statement for arbitrary bits satisfying reciprocity; the others
identify the Rédei matrix of $\mathbb Q(\sqrt{-d_B})$ with the bits, and deduce Rédei's formula
from the 4-rank statement.
