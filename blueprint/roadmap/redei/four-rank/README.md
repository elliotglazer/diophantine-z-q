# The 4-rank

Let $n>1$ be odd and squarefree, $t=|T_n|$, and let $\chi:\mathrm{Cl}\to\mathbb F_2^{\{q\mid n\}}$ be
the genus map, $c\mapsto(\chi_q(c))_q$. Counting gives
$$[\mathrm{Cl}:\mathrm{Cl}^2]=|\mathrm{Cl}[2]|\le2^{t-1}\le|\mathrm{im}\,\chi|=[\mathrm{Cl}:\ker\chi]\le[\mathrm{Cl}:\mathrm{Cl}^2],$$
so the principal genus theorem $\mathrm{Cl}^2=\bigcap_q\ker\chi_q$ holds and
$|\mathrm{Cl}[2]|=2^{t-1}$. Since $g(n)=|\mathrm{Cl}^2|$ is odd exactly when
$\mathrm{Cl}[2]\cap\mathrm{Cl}^2=1$, Rédei's theorem follows: $g(n)$ is odd if and only if the
kernel of the Rédei matrix is $\{0,e_n\}$, where $e_n$ is the exponent vector of $(\sqrt{-n})$.
