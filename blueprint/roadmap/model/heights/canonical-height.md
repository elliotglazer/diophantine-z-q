# The canonical height on $C(K_0)$

For $T\in C(K_0)$ the canonical height $\widehat h(T)$ is defined by
$$2\,\widehat h(T)=\lim_{m\to\infty}4^{-m}\,h_x\bigl([2^m]T\bigr).$$
Formally, $\widehat h(T)$ is half the limit of the real sequence $4^{-m}h_x([2^m]T)$; that the
sequence converges for every $T$ is proved, from the duplication height bounds, with the
basic properties of $\widehat h$. The factor $2$
is the manuscript's normalization, under which $2\widehat h$ is comparable with $h_x$.
