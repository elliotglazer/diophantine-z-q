# Quadratic fields

For an integer $d$ that is not the square of a rational number (for instance a squarefree
$d\ne1$), the field $K=\mathbb Q(\sqrt d)$ is a number field of degree $2$. The residue of
its Dedekind zeta function at $s=1$ is given by the class number formula, and this section
bounds each ingredient of that formula so as to bound the residue from below by
$\log\frac{1+\sqrt5}2/(6\sqrt{|d|})$.

- [The quadratic field $\mathbb Q(\sqrt d)$](quadratic-field.md)

The basis $1,\sqrt d$ bounds the discriminant; the real embeddings decide the signature;
roots of unity have order at most $6$.

- [The discriminant of $\mathbb Q(\sqrt d)$](discriminant-bound.md)
- [The signature of $\mathbb Q(\sqrt d)$](signature.md)
- [Roots of unity in a quadratic field](roots-of-unity.md)

An imaginary quadratic field has unit rank $0$ and regulator $1$; in a real quadratic field
every unit above $1$ is at least the golden ratio.

With the class number at least $1$ this bounds the residue.
