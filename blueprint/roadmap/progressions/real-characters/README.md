# Real characters

A real nonprincipal character $\chi$ agrees, on primes not dividing $2q$, with the Legendre
symbol $(d/\cdot)$ of a squarefree $d\ne1$ with $|d|$ dividing $q$. Through the factorization of the
Dedekind zeta function of $\mathbb Q(\sqrt d)$, the value $L(1,\chi)$ is the residue
$\kappa_K$ times finitely many local factors, each at least $(p-1)/(p+1)$; the residue bound
of the quadratic fields section then gives $|L(1,\chi)|\ge1/(40q^{3/2})$.
